# Glossary: German (de) – Beyond the Belt

Address: informal "du" (standard for German games). Buttons: infinitive ("Modul prüfen");
instructions: imperative ("Klicke ..."). Decimal comma and German thousands dot in literal
text (0,5 / 10.000); percent stays "50%" (no space, saves UI room).
