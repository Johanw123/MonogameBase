AI-generated content
====================

Assets in this game that were made by an AI model rather than taken from an
asset pack or drawn by a person. Add an entry when generated content is
committed; remove it if a person redraws the asset.

Effects drawn by code at runtime (shape glows, beams, trails) are not listed.

Each entry: path (relative to this folder), what it is, how it was made, date
added, and whether the game uses it.


Made by Claude (Anthropic) in Claude Code
-----------------------------------------

Content/Textures/Railgun/railgun.png
  Railgun turret sprite (64x17 px, points right), drawn on the homebase hull.
  A Python/Pillow script placed each pixel. The palette was sampled from the
  Foozle "Nairan - Battlecruiser - Base" hull sprite; no other image was used
  as a source. The script was not kept, so edit the PNG directly.
  Added 2026-10-06. Used in game.

Content/Textures/WeaponIcons/railgun.png
  Railgun upgrade icon (32x32 px pixel art, scaled x16 to 512x512).
  A pixel map written as text and rendered with Pillow, then given a black and
  red outline to match the other weapon icons. It uses the same palette as the
  turret sprite. The script was not kept, so edit the PNG directly.
  Added 2026-10-06. Used in game.

Content/Localization/*.json (every language except en.json)
  Translations of all player-facing text into 18 languages, written by Claude
  from the English keys (one translator per language, each with its own
  glossary). Not reviewed by native speakers yet. The English tooltips in
  Content/Data/upgrades*.json were also shortened by Claude the same day.
  Added 2026-10-07. Used in game.


Made by Claude (Anthropic) in Antigravity
-----------------------------------------

Content/Textures/Gems/plasma_orb.png
  World gem pickup sheet (128x128 px, 2x2 grid of four 64x64 px variants):
  faceted crystal-ore clusters bursting out of dark planetary crust rock with a
  soft outer glow aura, packed into GemShader.fx's surface channels so the
  crystals and glow take each gem type's tint while the rock base stays dark.
  Uses rock/asteroid meshes from the Synty POLYGON Generic and POLYGON Sci-Fi
  Space packs combined with procedural crystal shards, materials and lighting
  written in tools/blender/prerender.py (render_plasma_orb, CRYSTAL_ORE_VARIANTS),
  then packed by tools/build_gem_surface.py from RawAssets/Prerender/plasma_orb.
  Added 2026-10-15, replaced 2026-10-16. Used in game.

Content/Textures/Prerender/Planets/planet_crystal.png
  The mined planet, one revolution in 77 frames of 288 px (9-column sheet).
  The model (SM_Env_Planet_01) and the land mask texture are from the Synty
  POLYGON Sci-Fi Space pack; the material approximating Synty's planet shader,
  its colours and the lighting were written by Claude in
  tools/blender/prerender.py (render_planet_spin, CRYSTAL_PLANET). Packed by
  tools/build_prerender_sheet.py from RawAssets/Prerender/planet_crystal.
  Added 2026-10-15. Used in game.

Content/Textures/Gems/core_shard.png
  Core Shard icon and world pickup sprite (64x64 px): a tall, faceted golden
  crystal spire with smaller flanking needles erupting from a dark,
  magma-cracked planetary inner-core rock base with a soft golden aura.
  Uses rock meshes from the Synty POLYGON Generic pack combined with procedural
  crystal spires, magma fissure geometry, lighting and solar-gold compositing
  written in tools/blender/prerender.py (render_core_shard; raw passes in
  RawAssets/Prerender/core_shard).
  Added 2026-10-16. Used in game.

Content/Textures/Gems/prestige_orb.png
  Prestige Point icon and flight sprite (64x64 px): a Singularity / Time-Loop
  Orb with a deep black-violet event horizon, white-lilac photon ring,
  gravitationally lensed upper and lower arches, and a tilted swirling
  violet/lilac accretion disk modulated by a 3D faceted accretion ring rendered
  in Blender. Written in tools/blender/prerender.py (render_prestige_orb; raw
  pass in RawAssets/Prerender/prestige_orb).
  Added 2026-10-16. Used in game.

Content/Textures/Prerender/Weapons/rocket_main.png
Content/Textures/Prerender/Weapons/rocket_mini.png
  Main rocket projectile strip (512x128 px, 8 frames of 64x128 px) and Cluster
  Warheads mini-rocket projectile strip (384x96 px, 8 frames of 48x96 px).
  Uses the SM_Prop_Missile_07 and SM_Prop_Missile_03 meshes plus the
  SM_Flame_Mesh_New, Gradient_Boost_01 and Sphere_Glow_01 FX assets from the
  Synty POLYGON Sci-Fi Space pack, with glowing orange warhead/body bands,
  cyan nozzle core and animated cyan thruster plume compositing written in
  tools/blender/prerender.py (render_rocket_strip, render_rockets).
  Added 2026-10-17. Used in game.

Content/Textures/Prerender/Weapons/harpoon_anchor.png
  Arc Harpoon projectile and anchor strip (512x96 px, 8 frames of 64x96 px):
  a 3D barbed sci-fi harpoon spear with swept-back steel barbs, a glowing
  electric-cyan capacitor ring collar, warm orange Synty hull band and a
  pulsing cyan tether coupler socket. Uses the SM_Prop_Missile_01 and
  SM_Wep_Sword_Double_01 meshes plus the Sphere_Glow_01 FX asset from the Synty
  POLYGON Sci-Fi Space pack, with mesh shaping, lighting and animated electric
  cyan glow compositing written in tools/blender/prerender.py
  (render_harpoon_strip).
  Added 2026-10-17. Used in game.

Checked and not AI-generated (audit on 2026-10-06)
--------------------------------------------------

  These were checked by comparing files against the asset packs and by reading
  every earlier Claude Code and Codex session that worked on this game.
  Neither agent ever used an image-generation tool.

  Content/Textures/WeaponIcons/auto_cannon.png, laser.png, rockets.png
    Exact 16x nearest-neighbour upscales of the Foozle Pickups Pack icons
    ("Pickup Icon - Weapons - Auto Cannons / Zapper / Rocket", first frame),
    made by a Claude Code script on 2026-10-04. Pack art, only resized.
  Content/Textures/scifi_icons (upgrade, signal and module icons)
    All 103 icons the game references are byte-identical to the files in
    "250sci fi icons flat kat grabowska.zip".
  Content/Textures/craftpix_icons, Foozle_* packs, Gems, GUI
    Purchased or downloaded packs; no session wrote into these folders.
  Content/Atlases/fleet.png, icons.png
    Packed from pack sprites by tools/ scripts (see tools/README-*.md).
    Fleet also includes the prerendered ships listed above. Repacked by Codex
    with transparent hull margins and isolated outline samples using
    tools/build_fleet_atlas.py on 2026-10-17; source artwork unchanged.
  Content/Textures/logo_4k.png
    Exported from RawAssets/logo_4k.kra: a vector text layer with a gradient.
