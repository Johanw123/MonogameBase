# Thai (th) glossary: Beyond the Belt

Style: concise game UI, neutral/imperative, no sentence-final periods (Thai does not use them);
sentences inside one string are separated by a normal space, as Thai does. U+200B (zero width
space) goes between words so the game can wrap lines; normal spaces around numbers and
placeholders. "x" multipliers stay in compact HUD text ({0}x, x{0}); prose uses "N เท่า".
Seconds: "วินาที" in prose, "วิ" as a compact suffix ({0:0}s -> {0:0} วิ).
Plurals: Thai has one form (no "|"); counted nouns use classifiers where natural
(เม็ด for gems, ลำ for ships/drones/beams, ลูก for rockets/bombs, ชิ้น for shards/modules).
