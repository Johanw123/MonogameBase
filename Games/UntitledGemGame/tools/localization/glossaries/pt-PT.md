# Glossary: pt-PT (Português europeu, AO90 spelling)

Register: the player is addressed as "tu" (imperative: Clica, Mantém premido, Arrasta, Gasta).
Buttons use infinitives (Aplicar, Cancelar, Sondar, Remover). Names of upgrades, talents,
modules and signals use title case (major words capitalized). pt-PT spelling: ecrã, rato,
guardar, definições, bónus, génese, tectónico, iónico, projétil, rutura, fratura, detetor,
coleção, inspeção, reator.

Numbers: literal decimals in the text keep the point (0.5) so they match the numbers the game
formats at runtime with InvariantCulture; literal thousands use a space (10 000) because
"10,000" reads as ten in Portugal.
