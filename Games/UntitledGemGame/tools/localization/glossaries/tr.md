# Turkish (tr) glossary: Beyond the Belt

Style: informal "sen" imperatives for actions ("Tıkla", "Basılı tut"), present simple
(geniş zaman) for upgrade effects ("Gezginler daha hızlı uçar."). Concise UI tone.

Conventions
- Percent sign before the number, Turkish style: "%50", "+%25", "{0}%" -> "%{0}".
- Decimal point kept as "." (placeholders are formatted with InvariantCulture, so static
  text matches dynamic numbers: "0.5 saniye"). Thousands in static text: "10.000".
- Seconds: "saniye" in prose, "sn" in compact readouts ("{0:0.##} sn", "birim/sn").
  Minute: "dk" ("{0} / dk").
- Multipliers kept as "2x", "x4"; in prose "iki kat", "üç kat".
- Plurals: Turkish uses the singular after numbers, so both forms are identical
  ("{0} güç hücresi|{0} güç hücresi").
- No case suffixes are attached to placeholders (vowel harmony unknown); sentences are
  built with postpositions ("{2} için", "{1} içinde") or "Label: {0}" forms.
- ALL-CAPS uses Turkish casing (i -> İ, ı -> I): KİLİTLİ, GİZLİ.
