# Glossaire FR : Beyond the Belt

Registre : vouvoiement pour les consignes ("Cliquez", "Maintenez"), infinitif pour les boutons
("Annuler", "Lancer la boucle"). Typographie française : espace avant `:`, `!`, `?`, `%`
(espace normale ; le moteur ne coupe jamais la ligne avant ces signes). Virgule décimale dans
le texte fixe (0,5 seconde), espace pour les milliers (10 000). Apostrophe droite `'`, pas de
`œ` ni de `…` (polices des menus Gum en Latin-1). Multiplicateurs gardés à l'anglaise (`3x`, `x4`).
