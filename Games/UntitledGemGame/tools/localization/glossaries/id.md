# Glosarium Bahasa Indonesia (id) - Beyond the Belt

Gaya: UI game sci-fi yang ringkas. Pemain disapa dengan "kamu"/"-mu". Tombol memakai
imperatif ("Klik untuk...", "Pakai Semua"). Deskripsi peningkatan memakai kalimat aktif
orang ketiga ("Membuka...", "Menambah..."). Bentuk jamak: satu bentuk (tanpa `|`).
Angka mengikuti format game (titik desimal, sama seperti angka dinamis yang diformat
InvariantCulture). "s" (detik) -> "dtk".
