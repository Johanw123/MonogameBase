# Italian (it) glossary - Beyond the Belt

Style: sentence case for names (Italian convention: only the first word capitalized),
imperative "tu" for instructions ("Clicca", "Tieni premuto", "Spendi"). Numbers kept as in
English (the game formats placeholders with the invariant culture, so literal numbers match).

## Signal target phrases
Written without an article so they work in both "Aumento di {0}." / "Riduzione di {0}."
and "Totale: +5% {2}" (e.g. "velocità di tutte le raccoglitrici").
