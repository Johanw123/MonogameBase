# Czech (cs) glossary: Beyond the Belt

Address: informal singular ("ty"): "Klikni", "Získáš", "tvoje flotila". Buttons use
infinitives ("Pokračovat", "Utratit vše"). No gendered past forms for the player.
Decimals use a comma in literal text (0,5 s; 12,5%); thousands use a space (10 000).
Seconds: "s" with a space ("5 s"). Units: "jednotek" / "j." ("j./s").
Name capitalization: Czech sentence case for names ("Gravitační studna", "Roj dronů").
Names inside templates that need a case are introduced by a generic noun in nominative
("loď {0}", "talentu {0}", "systému {0}").
