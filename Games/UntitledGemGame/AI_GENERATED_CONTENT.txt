AI-generated content
====================

Assets in this game that were made by an AI model rather than taken from an
asset pack or drawn by a person. Add an entry when generated content is
committed; remove it if a person redraws the asset.

Effects drawn by code at runtime (shape glows, beams, trails) are not listed.

Isometric prototype rendered by Codex through Blender MCP
---------------------------------------------------------

Content/Textures/Isometric/ship-{basic,advanced,perimeter,expert,ultimate,drone}-00.png through -09.png
Content/Textures/Isometric/ship-home-00.png through -07.png
Content/Textures/Isometric/ship-home-emission-00.png through -07.png
  Seven ship appearances from the user's licensed Synty POLYGON Sci-Fi Space pack.
  Basic: SM_Ship_Fighter_01; advanced: SM_Ship_Fighter_Heavy_01;
  perimeter: SM_Ship_Stealth_01; expert: SM_Ship_Bomber_01;
  ultimate: SM_Ship_Cruiser_01; drone: SM_Veh_Drone_Repair_01;
  homebase: SM_Ship_Cruiser_01, with the red/cyan main-ship treatment below.
  128 headings and five bank poses per moving type; homebase has 128 level
  poses. Fleet frames are 256x256, supersampled from 512x512 EEVEE renders.
  The homebase uses 512x512 frames from 1024x1024, plus separate emission maps. Original UVs/normals, the supplied palette atlas
  and cyan-tinted emissive mask. Each mesh fits a radius-1.3 sphere in a
  3.7-wide orthographic canvas; runtime maps this to its existing pickup radius.
  Codex authored export_synty.py, export_main_ship.py and pack_synty_fleet.py.
  Warm key, cool fill,
  violet rim lighting; shared camera elevation 55 degrees. No generated source mesh
  or texture. Source package remains outside the repo in the user's Unity project.
  Added 2026-10-14; replaced with distinct Synty fleet on 2026-10-15.
  Used when the isometric prototype is enabled.

Main ship red/cyan treatment (2026-10-15)
  export_main_ship.py renders SM_Ship_Cruiser_01 at 55 degrees elevation with
  stronger warm key/cool fill/violet rim lights and small two-segment bevels.
  A Blender material remaps the supplied atlas's blue paint to red and gold
  trim to cyan, retaining neutral framing. The supplied Ship_Mask_04 detail map
  uses the mesh's panel UV channel. Native emissive details and the cyan strips
  emit at strength 2.5. A separate emission-only pass supplies runtime bloom;
  the opaque beauty pass composites afterwards at full brightness.
  Eight 2048x2048 beauty pages and eight emission pages, 16 frames per page.
  No generated source geometry/texture; original asset pack stays unchanged.

Shared lighting and compositing pass (2026-10-15)
Content/Textures/Isometric/ship-{basic,advanced,perimeter,expert,ultimate,drone}-00.png through -09.png
Content/Textures/Isometric/ship-{basic,advanced,perimeter,expert,ultimate,drone}-emission-00.png through -09.png
Content/Textures/Isometric/planet-emission-00.png through -07.png
  Fleet beauty frames rerendered with the same 55-degree camera, AgX exposure 0,
  light energies (1050/280/650), panel-detail material, roughness 0.48,
  strength-2.5 cyan trim emission and fine bevels as the homebase. The shared
  settings and material graph live in tools/blender/render_style.py.
  Blender's compositor writes beauty and emission in one render; intermediate
  emission is ZIP-compressed half-float OpenEXR. pack_synty_fleet.py converts
  linear emission to straight-alpha sRGB using OpenEXR/NumPy/Pillow.
  Fleet emission uses 128x128 frames in sixty 1024x1024 pages; planet emission
  uses 256x256 frames in eight pages (last 1024x512). Planet surface rerendered
  with shared lighting/color management and a Fresnel-masked natural rim.
  Ore orientations rerendered with the same lighting, camera and color settings.
  At runtime all surfaces composite after bloom at full brightness; only
  emission/highlights enter bloom, with a shared intensity. Ore retains its
  resource-color shader, GPU flight animation and highlight-driven colored glow.
  No generated source models or masks. Original pack files remain unchanged.
  Added/replaced 2026-10-15. Used by the isometric prototype.

Content/Textures/Isometric/planet-00.png through planet-07.png
  120 rotating purple/white faceted planet frames, 512x512, across eight pages.
  Rendered at 1024x1024 from Synty's SM_Env_Planet_14.fbx, with flat normals.
  Codex recreated PolygonSpace_Planet_02_B using the supplied land mask,
  triplanar projection, its original palette and combined contrast stages.
  Pole stays vertical on screen; no sideways axial tilt. Shared AgX view
  transform at exposure 0 and the same three lights as the homebase.
  No generated source mesh or mask. Same exporter and packing as the fleet.
  Added 2026-10-14; replaced with upright purple Synty planet on 2026-10-15.
  Used when the isometric prototype is enabled.

  No generated source model or texture. Same exporter and packing as the fleet.
  Added 2026-10-14; replaced with Synty ore on 2026-10-15. Used in the prototype.

Made by Claude (Anthropic) in Claude Code
-----------------------------------------

Content/Textures/Railgun/railgun.png
  Railgun turret sprite (64x17 px, points right), drawn on the homebase hull.
  A Python/Pillow script placed each pixel. The palette was sampled from the
  Foozle "Nairan - Battlecruiser - Base" hull sprite; no other image was used
  as a source. The script was not kept, so edit the PNG directly.
  Added 2026-10-06. Used in game.

Content/Textures/WeaponIcons/railgun.png
  Railgun upgrade icon (32x32 px pixel art, scaled x16 to 512x512).
  A pixel map written as text and rendered with Pillow, then given a black and
  red outline to match the other weapon icons. It uses the same palette as the
  turret sprite. The script was not kept, so edit the PNG directly.
  Added 2026-10-06. Used in game.

Content/Localization/*.json (every language except en.json)
  Translations of all player-facing text into 18 languages, written by Claude
  from the English keys (one translator per language, each with its own
  glossary). Not reviewed by native speakers yet. The English tooltips in
  Content/Data/upgrades*.json were also shortened by Claude the same day.
  Added 2026-10-07. Used in game.

Checked and not AI-generated (audit on 2026-10-06)

  These were checked by comparing files against the asset packs and by reading
  every earlier Claude Code and Codex session that worked on this game.
  Neither agent ever used an image-generation tool.

  Content/Textures/WeaponIcons/auto_cannon.png, laser.png, rockets.png
    Exact 16x nearest-neighbour upscales of the Foozle Pickups Pack icons
    ("Pickup Icon - Weapons - Auto Cannons / Zapper / Rocket", first frame),
    made by a Claude Code script on 2026-10-04. Pack art, only resized.
  Content/Textures/scifi_icons (upgrade, signal and module icons)
    All 103 icons the game references are byte-identical to the files in
    "250sci fi icons flat kat grabowska.zip".
  Content/Textures/craftpix_icons, Foozle_* packs, Gems, GUI
    Purchased or downloaded packs; no session wrote into these folders.
  Content/Atlases/fleet.png, icons.png
    Packed from pack sprites by tools/ scripts (see tools/README-*.md).
  Content/Textures/logo_4k.png
    Exported from RawAssets/logo_4k.kra: a vector text layer with a gradient.

Content/Textures/Backgrounds/nebula-3.png
  3840x2160 background rendered by Codex through Blender MCP from the user's
  /home/johan/Downloads/Nebula+3.hdr (7680x4320). No generated source texture.
  tools/blender/export_nebula_background.py builds an isolated environment-only
  scene, panoramic camera at yaw 0/pitch 0, equirectangular crop spanning
  160 degrees horizontally and 90 vertically, AgX exposure -1; Cycles one
  sample (direct sky rays). Rerendered with the wider view on 2026-10-15.
  finish_nebula_background.py applies a Pillow RGB curve x/(x+32), scaled to
  255, to retain dim cloud detail under the game's below-bloom brightness tint.
  Source HDR and the open ship scene are unchanged. Added 2026-10-15.
  Used by the development game's Nebula 3 background toggle.
