# Team Jape: short-form gameplay and posting guide

Team Jape is the developer account. Beyond the Belt is the current game. Use this guide for gameplay reveals, feature demonstrations, and development updates across Instagram, TikTok, YouTube Shorts, Facebook, and X/Twitter.

## Quick platform reference

| Platform | Our video export | Description approach | Link call to action | Suggested hashtags |
| --- | --- | --- | --- | --- |
| Instagram Reels | Vertical 9:16 | Hook, a little context, one next step | “Link in bio” when the profile link is set | 3–5 relevant tags |
| TikTok | Vertical 9:16 | Short hook tied to the action on screen | “Link in bio” only if a working website link is available; otherwise “Follow for development updates” | 3–5 relevant tags |
| YouTube Shorts | Vertical 9:16 | Clear title; short description naming the game and feature | “Game page linked on our channel profile” | 2–3 in the description |

These are our export preferences, not exclusive platform requirements. The shorts skill renders the vertical version; for a square X version, capture the same scenes at `"width": 2880, "height": 2880` and render an edit with `"size": [1080, 1080]`.

## Write the post around what the clip actually shows

Use **a concrete hook → the game or development context → one next step**. A gameplay post can explain the experience; a development post can explain what changed and why. Keep development claims accurate: do not call a feature new or improved unless it actually is.

- Use the game name in normal text as well as, optionally, a hashtag.
- Use player-facing tags such as `#IndieGame`, `#IncrementalGame`, or `#SpaceGame` for gameplay. Use `#GameDev`, `#IndieDev`, or `#GameDevelopment` when discussing the development process.
- `#BeyondTheBelt` identifies this game; `#TeamJape` can identify studio-wide posts. Neither needs to appear in every post.
- Prefer tags that describe the clip. Use `#PixelArt` for relevant visuals, `#MonoGame` for engine-focused posts, and `#ScreenshotSaturday` for an appropriate Saturday update. Do not use `#MadeWithUnity` for this MonoGame project.
- Choose one main ask: follow, give feedback, visit the game page, or wishlist. Use “Wishlist on Steam” only when the actual Steam page is live. Do not imply a demo is available unless it is publicly available.
- Replace `[GAME_URL]` with a real destination before publishing. Link-in-bio/profile examples assume that destination is already added and works. Without a game page, use a follow/feedback ask instead.

## Instagram

Put a short hook on the first line and hashtags at the end. “Link in bio” is a useful default because ordinary caption URLs generally are not clickable. Some Meta Verified creators have access to a caption-link test, so use that only if the account actually has it. [Caption-link rollout reporting](https://www.socialmediatoday.com/news/instagram-tests-links-in-post-captions-for-paying-users/814763/)

Keep the set at five tags or fewer; Instagram announced a rollout limiting post and Reel captions to five. [Instagram hashtag announcement coverage](https://www.socialmediatoday.com/news/instagram-implements-new-limits-on-hashtag-use/808309/)

### Gameplay example

```text
One harvester. Then the fleet takes over. 🚀

A look at progression in Beyond the Belt, our incremental space game in development at Team Jape.

Explore the game — link in bio.

#IndieGame #IncrementalGame #IdleGame #SpaceGame #BeyondTheBelt
```

### Development / feedback example

```text
Can you follow the action when the whole fleet gets busy?

A look at the collection effects in Beyond the Belt. We want those big hauls to feel satisfying while keeping the gameplay readable.

What catches your eye first?

#GameDev #IndieDev #GameDevelopment #PixelArt #BeyondTheBelt
```

If the game page supports wishlisting, replace the gameplay call to action with `Wishlist Beyond the Belt on Steam — link in bio.`

## TikTok

Keep the caption short enough that the clip supplies most of the explanation. Start with 3–5 relevant tags; this is our suggested working set, not a guarantee or a requirement to use all five.

Only say “link in bio” if viewers can actually use a website link. TikTok documents website-link eligibility as 1,000 followers or a Registered Business Account; availability can vary by region. [TikTok profile-link help](https://support.tiktok.com/en/getting-started/setting-up-your-profile/linking-another-social-media-account)

### Gameplay example — works without a website link

```text
It starts with one harvester. Then this happens. 💎

Beyond the Belt — an incremental space game by Team Jape. Follow to see it grow.

#IndieGame #IncrementalGame #IdleGame #SpaceGame #BeyondTheBelt
```

### Development / feedback example

```text
How much gem chaos is too much? 👀

Testing ability combinations in Beyond the Belt. Would you keep the effects this busy?

#GameDev #IndieDev #IncrementalGame #PixelArt #BeyondTheBelt
```

With a working game link, replace the follow line with `Explore Beyond the Belt — link in bio.`

## YouTube Shorts

Use a descriptive title rather than the export filename. Put the game name and feature in the description, and add a small hashtag set at the end. YouTube supports hashtags in titles and descriptions; our default is to keep the title readable and put them in the description. [YouTube hashtag help](https://support.google.com/youtube/answer/10806146?hl=en)

**External URLs in Shorts descriptions and comments are not clickable.** Link the game from the channel profile and point there. A related-video link can direct viewers to another YouTube video when the feature is available; it is not a direct Steam link. [YouTube link guidance](https://support.google.com/youtube/answer/13748639?hl=en)

### Gameplay example

Title:

```text
From One Harvester to a Whole Fleet | Beyond the Belt
```

Description:

```text
One harvester becomes a busy fleet in Beyond the Belt, an incremental space game in development by Team Jape.

Explore the game through the link on our channel profile.

#IndieGame #IncrementalGame #BeyondTheBelt
```

### Development / feedback example

Title:

```text
Making a Busy Fleet Readable | Beyond the Belt Devlog
```

Description:

```text
A look at collection effects and ability combinations in Beyond the Belt. We're working on making a busy screen satisfying to watch and easy to follow.

Which effect stands out to you?

#GameDev #IndieDev #BeyondTheBelt
```

Use the devlog example for a clip that actually discusses or compares readability, not an unrelated gameplay montage. For a gameplay-only abilities clip, use `When Abilities Combine | Beyond the Belt` instead.

## Facebook

Give viewers a little context about the game and Team Jape. Use 0–3 relevant hashtags as a starting point; they are optional. A regular Page post can contain a direct website link. For a Reel, check the posting interface and preview before assuming a pasted URL is tappable; the example below points to the Page's website link instead.

### Reel gameplay example

```text
From a single harvester to a whole fleet. 🚀

This is Beyond the Belt, an incremental space game we're developing at Team Jape. This clip shows how the fleet grows across different stages of the game.

Find the game through the website link on our Page.

#IndieGame #IncrementalGame #BeyondTheBelt
```

### Regular Page development post

```text
A look behind the scenes at Beyond the Belt.

We're exploring how different abilities work together as the fleet grows. Here's one combination in action.

Explore the game: [GAME_URL]

#GameDev #IndieGame
```

If the account's composer does not allow the link, use the Page website link and adjust the wording. When posting in a Facebook group, follow that group's self-promotion rules and write for its audience rather than copying a Page promotion unchanged.

## X / Twitter

Yes, X supports hashtags. Use one or two relevant ones when they help describe the post; zero is also reasonable. X's own guidance recommends no more than two, rather than an Instagram-style block. [X hashtag guidance](https://help.x.com/en/using-x/how-to-use-hashtags)

Put a direct game URL in the post when visiting the game page is the goal. You do not need “link in bio” here. [X link guidance](https://help.x.com/en/using-x/how-to-post-a-link)

### Gameplay example

```text
One harvester to a whole fleet. 🚀

A look at progression in Beyond the Belt, our incremental space game.

Explore the game: [GAME_URL]

#IndieGame #IncrementalGame
```

### Development / feedback example

```text
Testing ability combinations in Beyond the Belt. The fleet gets busy fast.

Does the collection effect read clearly, or is it too much visual noise?

#GameDev #IndieDev
```

These are intentionally short for a standard post. Check the composer after replacing the link or adding mentions. Keep the square video as the focal point and use the post text for context.

## Make shorts with the beyond-the-belt-shorts skill

[Skills/beyond-the-belt-shorts](Skills/beyond-the-belt-shorts/SKILL.md) makes a short end to end from new footage, for Claude Code and Codex alike:

1. **Stage** any game state in a scene file: a debug preset plus exact upgrade levels, currencies, stats, abilities, modules and signals.
2. **Record** it with the game's own capture mode (`--capture scene.json`). The game renders offscreen in a native 9:16 play field at 4K/60, on a fixed timestep, with scripted clicks, holds, gravity wells, abilities, upgrades and zooms. Every sound the game plays is logged, so the real game audio can be rebuilt.
3. **Edit** to music with `render_short.py`: punch-ins, slow pushes, slow motion, honest live numbers from the capture log, and text in the `fullscreen` layout (default).

Work folders live in `Marketing/Shorts/NN-slug/` (scenes and edit files are versioned; takes and renders are ignored by Git). The capture mode never uses the player's save or `Settings.json`, and only runs in development builds (`Demo.IsDev`).

### Install

The skill is linked, not copied, so edits in the repo apply immediately:

```bash
ln -sfn "$PWD/Marketing/Skills/beyond-the-belt-shorts" ~/.claude/skills/beyond-the-belt-shorts
ln -sfn "$PWD/Marketing/Skills/beyond-the-belt-shorts" "${CODEX_HOME:-$HOME/.codex}/skills/beyond-the-belt-shorts"
```

### Example prompts

```text
Make a 20-second short showing the graviton cascade chaining through a late-game swarm. Fullscreen layout, Sky Fish as music.
```

```text
Make a progression short: one ship clicking red gems, then the late-game fleet. Put the switch on the music drop and show the real gem counts.
```

```text
Make a short in the banners layout about the shipyard: equipping a module and the fleet using it.
```

### Run the tools directly

From the game directory:

```bash
S=Marketing/Skills/beyond-the-belt-shorts/scripts
python3 $S/capture.py --list Marketing/Shorts/catalog.json         # every preset, upgrade, stat, ability, module, signal
python3 $S/capture.py Marketing/Shorts/01-first-click/scenes/*.json --preview  # quick 540x960 takes and contact sheets
python3 $S/capture.py Marketing/Shorts/01-first-click/scenes/*.json            # 4K takes + game audio + sheets
python3 $S/render_short.py Marketing/Shorts/01-first-click/edit.json            # final MP4 + review sheet
```
